# 🩸 Rakta Vahini

## 📌 Project Title
**Rakta Vahini – Smart Blood Donor Management System**

Rakta Vahini is an Android-based blood donor management application developed to simplify and accelerate the process of finding eligible blood donors during emergencies. The application replaces inefficient social media forwards with a smart and filtered donor network.

---

## ❗ Problem Statement

During emergencies, blood procurement often depends on WhatsApp forwards, calls, and social media messages, which are slow, unreliable, and frequently reach medically ineligible or incompatible donors.

Rakta Vahini solves this issue by providing a structured platform that filters blood donors based on:

- Blood Group Compatibility
- Medical Eligibility (90-Day Donation Rule)
- Nearby Location Radius

This enables faster, safer, and more reliable blood donor discovery.

---

## ✨ Features

### 🔐 Authentication System
- User Signup & Login using Firebase Authentication
- Email Verification for secure access

### 👤 Donor Profile Management
- Register donor details
- Blood Group selection
- Last Donation Date tracking
- Location-based registration

### 🔍 Smart Donor Search
- Search donors by required blood group
- View only compatible donors

### ✅ Eligibility Filtering
- Automatic 90-day donation eligibility validation
- Prevents medically ineligible donor visibility

### 📍 Location-Based Filtering
- GPS integration for nearby donor search
- Radius-based filtering (10km / 20km)

### 📞 Secure Contact
- Call donors using Android Intents
- Protects donor privacy by avoiding direct number exposure

### 🩸 Donation Tracking
- Donation history log
- Record previous blood donations

### 🟢 "I Am Eligible" Toggle
- Donors can manually update immediate availability

### 🔔 Notifications
- Thank-you notification after successful donation logging
